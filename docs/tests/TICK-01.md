### [ TICK-01] [Création d'un ticket avec des données valides]

- **Objectif :** Vérifier si le formulaire de création de ticket est fonctionnelle
- **Préparation :** Compte connecté, dépard du test page new-ticket
- **Données utilisées :** 
    - titre du ticket : "Mot de passe expiré, compte verrouillé"
    - Catégorie : Réseau
    - Priorité : URGENT
    - image : captureVPN.png
    - description : "Depuis ce matin, impossible de me connecter à mon poste et à ma messagerie." 

- **Actions :**
  1. Se connecter
  2. Se rendre sur la page de création de ticket
  3. Saisir les informations du formulaire de création de ticket valide
  4. Soumettre le formulaire
  5. Vérifier si le ticket et bien affiché dans la page ticket
- **Résultat attendu :** Un message de succès doit être affiché "Le ticket "n°ticket + nom du ticket " à bien été créer".  
- **Résultat obtenu :** Le ticket est bien créer et est affiché dans la page des tickets
- **Statut :**  exécuté

Statuts du test   :

- **Réussi** : le résultat obtenu correspond au résultat attendu.
