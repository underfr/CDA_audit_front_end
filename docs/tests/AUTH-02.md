### [ AUTH-02] [Connexion avec les données invalides]

- **Objectif :** Vérifier si le formulaire de connexion bloque si des informations ne sont pas correcte.
- **Préparation :** Compte nom connecté, dépard du test page login
- **Données utilisées :** Identifiant / mot de passe
- **Actions :**
  1. Se rendre sur la page login
  2. Saisir de mauvaise informations de connexion
  3. Soumettre le formulaire
- **Résultat attendu :** Un message d'erreur doit être affiché "identifiant ou mot de passe incorect ".
- **Résultat obtenu :** [À compléter après le test]
- **Statut :** non exécuté

Statuts du test :

- **Réussi** : le résultat obtenu correspond au résultat attendu.
- **Échoué** : le résultat obtenu ne correspond pas au résultat attendu.
- **Bloqué** : un problème empêche d’effectuer la vérification.
- **Non exécuté** : le test n’a pas été lancé.
